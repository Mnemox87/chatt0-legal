# Chatt0 — legal texts

The End User Licence Agreement and Privacy Policy for
[Chatt0](https://store.steampowered.com/app/5180170/), published here because
a store page has to link a copy anyone can reach.

- [End User Licence Agreement](https://mnemox87.github.io/chatt0-legal/terms/)
- [Privacy Policy](https://mnemox87.github.io/chatt0-legal/privacy/)

These pages are the same text the application itself displays, generated from
its source rather than copied, so the two cannot drift apart. Chatt0 is
peer-to-peer messaging software: there is no server and no account database,
which is most of why the privacy policy is as short as it is.
